How It Works
01 You submit a news headline + source URL to the Intelligent Contract on GenLayer Bradbury Testnet
02 Multiple independent AI validators each independently fetch the live source URL using gl.get_webpage()
03 Each validator's LLM analyses the page content against the headline, deciding: REAL / FAKE / MISLEADING
04 Optimistic Democracy consensus — validators must agree on the verdict via the Equivalence Principle
05 The final verdict is stored permanently on-chain — immutable, verifiable, trustless
